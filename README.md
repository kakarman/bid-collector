# 나라장터 입찰정보 자동 수집 & 메일 발송 시스템

> 코딩을 전혀 몰라도 따라 할 수 있게 만든 가이드입니다.
> 순서대로만 하시면 **1시간 안에** 세팅이 끝납니다.

---

## 0. 이 시스템이 하는 일

```
매일 오전 10시 (또는 내가 버튼 누를 때)
        ↓
조달청 나라장터 Open API 접속
        ↓
[사업계획] · [사전규격] · [본공고]  신규 공고 수집
   (전날 10시 ~ 오늘 10시 / 월요일은 금·토·일까지)
        ↓
내가 정한 키워드가 들어간 건만 골라내기
        ↓
엑셀 파일 1개로 정리
        ↓
내 이메일로 자동 발송 📧
```

**필요한 파일은 3개뿐입니다.**

| 파일 | 역할 |
|---|---|
| `main.py` | 실제로 일하는 프로그램 |
| `requirements.txt` | 필요한 부품 목록 |
| `.github/workflows/bid_collector.yml` | "매일 10시에 실행해줘" 라는 예약표 |

## 1단계. 공공데이터포털 회원가입 & API 키 발급 (약 15분)

### 1-1. 회원가입

1. https://www.data.go.kr 접속
2. 우측 상단 **회원가입** → 일반회원으로 가입 (무료)

### 1-2. 필요한 API 3개를 "활용신청" 하기

아래 3개를 **각각** 신청해야 합니다. (셋 다 자동 승인이라 몇 분이면 됩니다)

| 순서 | API 이름 | 바로가기 |
|---|---|---|
| ① | 조달청_나라장터 **입찰공고정보서비스** | https://www.data.go.kr/data/15129394/openapi.do |
| ② | 조달청_나라장터 **사전규격정보서비스** | https://www.data.go.kr/data/15129437/openapi.do |
| ③ | 조달청_나라장터 **발주계획현황서비스** | https://www.data.go.kr/data/15129462/openapi.do |

각 페이지에서:

1. 오른쪽 위 파란색 **[활용신청]** 버튼 클릭
2. 활용목적 → **"기타"** 선택 후 `사내 영업용 입찰정보 수집` 정도로 입력
3. 아래 동의 항목 체크 → **신청**
4. 잠시 후 "승인" 상태가 됩니다 (대부분 즉시 자동승인)

> 💡 셋 다 신청하는 게 좋지만, ①②만 승인돼도 프로그램은 정상 작동합니다.
> (③이 안 되면 해당 단계만 자동으로 건너뜁니다)

### 1-3. 인증키 복사하기 ★중요★

1. 사이트 우측 상단 **마이페이지** → **개인API인증키 발급현황** (또는 **오픈API** → **개발계정**)
2. **일반 인증키 (Decoding)** 을 복사합니다.

> ⚠️ **Encoding** 이 아니라 **Decoding** 키를 쓰세요.
> (혹시 Encoding 키를 넣어도 프로그램이 자동으로 변환해주긴 합니다)

> ⏰ 신청 직후에는 키가 서버에 반영되기까지 **최대 1시간** 걸릴 수 있습니다.
> 처음 실행했을 때 오류가 나면 1시간 뒤 다시 해보세요.

## 2단계. Gmail "앱 비밀번호" 발급 (약 5분)

메일을 자동으로 보내려면 **평소 쓰는 구글 비밀번호가 아니라** 전용 비밀번호가 필요합니다.

1. https://myaccount.google.com/security 접속
2. **2단계 인증(2-Step Verification)** 을 먼저 **켭니다** (이미 켜져 있으면 통과)
3. https://myaccount.google.com/apppasswords 접속
4. 앱 이름에 `입찰정보수집` 이라고 입력 → **만들기**
5. 화면에 나오는 **16자리 비밀번호**를 복사해 둡니다. (예: `abcd efgh ijkl mnop`)
   - 공백은 있어도 되고 없어도 됩니다. 프로그램이 알아서 처리합니다.
   - **이 창을 닫으면 다시 볼 수 없으니** 메모장에 잠깐 붙여넣어 두세요.

> 2단계 인증을 켜지 않으면 '앱 비밀번호' 메뉴 자체가 보이지 않습니다.

## 4단계. 비밀정보(Secrets) 등록 ★가장 중요★ (약 5분)

API 키와 비밀번호를 코드에 직접 적으면 위험합니다.
GitHub의 **금고(Secrets)** 에 넣어두고 프로그램이 꺼내 쓰게 합니다.

1. 저장소 상단 **Settings** (⚙️ 톱니바퀴)
2. 왼쪽 메뉴 아래쪽 **Secrets and variables** → **Actions**
3. 초록색 **New repository secret** 버튼
4. 아래 **4개를 하나씩** 등록합니다. (이름 철자를 정확히 지켜주세요, 대문자입니다)

| Name (이름) | Secret (값) | 설명 |
|---|---|---|
| `SERVICE_KEY` | `abc123...` | 1단계에서 복사한 **Decoding 인증키** |
| `GMAIL_USER` | `saaad26@gmail.com` | 메일을 **보낼** 지메일 주소 |
| `GMAIL_APP_PASSWORD` | `abcdefghijklmnop` | 2단계에서 받은 **앱 비밀번호 16자리** |
| `MAIL_TO` | `saaad26@gmail.com` | 메일을 **받을** 주소 |

> 📬 여러 명에게 보내고 싶으면 `MAIL_TO` 값에 쉼표로 나열하세요.
> 예: `saaad26@gmail.com, teamlead@company.co.kr, sales@company.co.kr`

> 한 번 저장한 Secret 값은 다시 볼 수 없습니다. 바꾸려면 **Update** 로 덮어쓰면 됩니다.

## 6단계. 평소 사용법

### 🔘 원할 때 즉시 실행하기

**Actions** 탭 → 왼쪽에서 워크플로 선택 → **Run workflow** → 초록 버튼.
끝입니다. 하루에 몇 번을 눌러도 됩니다.

### 🔍 검색어 바꾸기

키워드는 **두 그룹**으로 나뉘어 있습니다.

| 그룹 | 성격 | 엑셀 표시 |
|---|---|---|
| `CORE_KEYWORDS` | 구체적인 장비명 (인큐베이터, 원심분리기, 흄후드…) | **★핵심** 🟨 |
| `WIDE_KEYWORDS` | 분야를 넓게 훑는 단어 (연구, 시험, 진단, 바이오…) | 참고 ⬜ |

둘 다 수집하되 엑셀 맨 앞 **중요도** 열로 구분되고, **★핵심이 항상 맨 위**로 올라옵니다.
바쁘시면 ★핵심만 보시고, 여유 있을 때 참고까지 훑으시면 됩니다.

**수정 방법**

1. 저장소에서 `main.py` 클릭 → 오른쪽 위 **연필 아이콘 ✏️**
2. 맨 위 `CORE_KEYWORDS` / `WIDE_KEYWORDS` 목록에서 단어를 추가·삭제
   ```python
   CORE_KEYWORDS = [
       '인큐베이터',
       '초저온냉동고',   ← 이런 식으로 한 줄 추가
   ]
   ```
3. 오른쪽 위 **Commit changes** → 저장 완료 (다음 실행부터 바로 적용)

**결과가 너무 많을 때**

- 노이즈가 심한 단어(`'진단'`, `'장비'`, `'시험'`, `'건조'`)를 `WIDE_KEYWORDS`에서 지우세요. 이 넷만 빼도 절반 가까이 줄어듭니다.
- 특정 분야가 계속 걸리면 `EXCLUDE_KEYWORDS`에 추가 (예: `'컨설팅'`, `'청소'`, `'급식'`, `'전철'`)
- 아예 ★핵심만 받고 싶으면 `WIDE_KEYWORDS = []` 로 비워도 됩니다.

### ⏰ 실행 시간 바꾸기

`.github/workflows/bid_collector.yml` 을 편집합니다.

```yaml
- cron: '0 1 * * 1-5'
```

깃허브는 **세계표준시(UTC)** 를 씁니다. **한국시간 − 9시간** 을 적으세요.

| 원하는 한국시간 | 넣을 값 |
|---|---|
| 오전 8시 | `'0 23 * * 0-4'` (전날로 넘어감) |
| 오전 9시 | `'0 0 * * 1-5'` |
| **오전 10시 (기본)** | `'0 1 * * 1-5'` |
| 오후 2시 | `'0 5 * * 1-5'` |
| 오후 6시 | `'0 9 * * 1-5'` |

- 맨 뒤 `1-5` = 월~금. 주말 포함하려면 `*` 로 바꾸세요.
- 시간을 바꿨다면 `main.py` 의 `DAILY_CUTOFF_HOUR = 10` 도 같은 시각으로 맞춰주세요.
- ⚠️ 깃허브 무료 스케줄러는 서버가 붐빌 때 **5~20분 늦게** 실행될 수 있습니다. (정상입니다)

### 📎 메일이 안 왔을 때 엑셀 받기

Actions → 해당 실행 클릭 → 화면 맨 아래 **Artifacts** → `bid-excel` 다운로드.

## 7. 자주 나는 문제 & 해결법

| 증상 | 원인 / 해결 |
|---|---|
| `필수 설정값 "SERVICE_KEY" 이(가) 비어 있습니다` | Secrets 이름 오타. 대문자로 정확히 `SERVICE_KEY` |
| `API 오류 [30] SERVICE KEY IS NOT REGISTERED` | 키가 아직 반영 안 됨 → **1시간 뒤 재시도**. 또는 해당 API 활용신청을 안 함 |
| `API 오류 [22] LIMITED_NUMBER_OF_SERVICE_REQUESTS` | 하루 호출 한도(개발계정 1,000회) 초과 → 다음 날 재시도하거나 포털에서 **운영계정 전환** 신청 |
| 메일 발송 실패 `(535, ...)` | 앱 비밀번호가 틀림. 일반 구글 비밀번호가 아니라 **앱 비밀번호 16자리** 여야 합니다 |
| 결과가 **0건** | 키워드가 너무 좁거나 그 기간에 실제로 없음 → `lookback_days=7` 로 수동 실행해 확인 |
| 결과가 **너무 많음** | `EXCLUDE_KEYWORDS` 추가, 또는 `BUSINESS_TYPES` 에서 `'용역'` 빼기 |
| 어느 날부터 자동 실행이 안 됨 | 깃허브는 **60일간 저장소 활동이 없으면** 스케줄을 자동 정지시킵니다. 아무 파일이나 한 번 수정(Commit)하면 다시 살아납니다 |
| `사업계획: 수신 0건` 이 계속 뜸 | 발주계획 API 미승인이거나 조달청이 주소를 변경한 경우입니다. **나머지 단계는 정상 작동**하니 그대로 쓰셔도 됩니다 |
| `Max retries exceeded` / `timed out` | **조달청 서버 쪽 문제입니다(내 잘못 아님).** 자동으로 3번까지 재시도하고, 그래도 안 되면 그 부분만 건너뛴 뒤 메일 맨 위에 ⚠️ 안내가 붙습니다. 누락이 걱정되면 `lookback_days=2` 로 수동 실행 한 번 |
| 메일 맨 위에 주황색 ⚠️ 박스가 보임 | 일부 항목을 못 가져왔다는 뜻입니다. 대부분 일시적이며, 다음 날 정상 수집됩니다 |

## 8. 알아두시면 좋은 점

### 📌 SMPP(공공구매종합정보망)에 대하여

요청하신 **공공구매종합정보망(smpp.go.kr)** 은 현재 **입찰공고 목록을 내려주는 Open API가 없습니다.**
공공데이터포털에 있는 SMPP 관련 API는 *성능인증 확인서*, *상생협력 확인서*, *직접생산확인 증명서* 같은
**기업 인증서 조회용**이라 신규 공고 수집에는 쓸 수 없습니다.

→ 그래서 말씀하신 대로 **조달청(나라장터) 데이터만 완벽하게** 수집하도록 만들었습니다.
   (참고로 지자체·공공기관 공고 대부분이 나라장터에 함께 올라오므로 실무 커버리지는 충분합니다.)

### 📌 "사업내용 요약" 열에 대하여

나라장터 API는 공고문 **본문 전체 텍스트를 제공하지 않습니다.**
대신 API가 주는 항목들(품명 · 규격 · 수량 · 계약방법 · 낙찰방법 · 참가자격 등)을 모아
한 칸에 정리해 넣었습니다. 더 자세한 내용은 **공고링크**를 눌러 확인하시면 됩니다.

### 📌 사전규격 공고링크에 대하여

2024년 **차세대 나라장터** 개통 이후 본공고와 사전규격의 상세화면 주소 체계가 서로 달라졌습니다.

- **본공고** → API가 상세주소를 직접 주므로 `공고 바로가기` 로 한 번에 열립니다
  (`g2b.go.kr/link/PNPE027_01/single/?bidPbancNo=...`)
- **사전규격** → API가 주소를 주지 않는 경우가 있어, 링크 칸이 비지 않도록
  **사전규격 검색화면 링크**를 자동으로 채워 넣습니다. 클릭 후 옆 칸의 **공고번호**
  (예: `R26BD00262407`) 를 붙여넣으면 해당 건이 바로 조회됩니다.

**직접 열리는 링크로 바꾸는 방법** — 나라장터에서 사전규격 공고를 아무거나 하나 연 뒤
브라우저 주소창의 주소를 복사해서, `main.py` 위쪽의 이 줄에 넣으면 됩니다.

```python
PRESPEC_LINK_TEMPLATE = 'https://www.g2b.go.kr/link/○○○○/single/?○○○={no}'
```

`{no}` 자리에 등록번호가 자동으로 들어갑니다. 이 줄을 채우는 순간부터
사전규격도 본공고처럼 클릭 한 번에 열립니다.

### 📌 점검 모드 (DEBUG_SHOW_FIELDS)

링크나 예산이 비어 있는 등 이상할 때, `main.py` 위쪽의

```python
DEBUG_SHOW_FIELDS = False   →   True
```

로 바꾸고 한 번 실행하면, API가 실제로 어떤 항목들을 주는지 Actions 로그에
전부 찍힙니다. 그 로그를 그대로 복사해 문의하시면 원인을 바로 찾을 수 있습니다.
확인이 끝나면 다시 `False` 로 돌려놓으세요.

### 📌 단계별 색상

엑셀의 `구분` 열은 색으로 구분됩니다.

- 🟡 **사업계획** (연노랑) — 아직 계획 단계, 가장 이른 접촉 시점
- 🔵 **사전규격** (연파랑) — 규격 사전공개, **영업 골든타임** (의견 제출 가능)
- 🟢 **본공고** (연초록) — 실제 입찰 진행 중

이 작업은 1회 실행에 1~3분이라 한 달에 60분도 안 씁니다.
